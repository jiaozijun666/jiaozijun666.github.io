1. Backend and Tool-Agent Orchestration for an Air-Gapped Railway Intelligence System

Developed a secure, on-premise LLM-based business support system for heavy-haul railway operations, integrating domain-adapted language models, RAG, knowledge graphs, multimodal processing, and intelligent workflow orchestration. The platform supports knowledge Q&A, document generation, meeting-minute generation, PPT generation, and operational decision support.

A key component is an intelligent meeting-minutes pipeline that combines railway-adapted Whisper ASR, speaker diarization, hierarchical LLM summarization, structured action-item extraction, and safety-rule checking to transform long meeting recordings into actionable minutes.

Tech: DeepSeek · RAG · Graph-RAG · Whisper · PaddleOCR · Neo4j · LangChain

2. Resource-Aware Benchmarking of Classical and Deep Time-Series Forecasters

View GitHub Repository →

Conducted a systematic comparison of classical and deep-learning forecasting models across five time-series datasets covering energy, air quality, manufacturing productivity, traffic volume, and biomedical signals. The study evaluated not only predictive accuracy, but also scalability, generalization, robustness, and computational efficiency.

Compared Prophet, LightGBM, DLinear, LSTM, Transformer, and DARNN under a consistent forecasting and evaluation pipeline. The results showed that deep models can achieve stronger accuracy on complex temporal patterns, while classical models often remain more efficient, stable, and practical under limited data or computational constraints.

Key Findings: DARNN achieved the lowest MAE and RMSE on several datasets, while LightGBM and DLinear offered substantially lower computational cost. Robustness experiments also showed that LSTM and DARNN were considerably less sensitive to small Gaussian perturbations than LightGBM.

Methods: Prophet · LightGBM · DLinear · LSTM · Transformer · DARNN · MAE / RMSE / MAPE · Robustness Testing

3. LLM-Assisted ESG Metric Extraction and Standardisation for Healthcare Reporting

View GitHub Repository →

Developed an automated ESG information extraction and analysis system that converts unstructured sustainability reports into structured, machine-readable ESG data. The pipeline combines PDF parsing, text cleaning, metric extraction, semantic matching, and language-model-based processing to identify ESG indicators, values, units, and qualitative information from heterogeneous corporate reports.

The extracted metrics are further integrated into a transparent ESG scoring framework covering Environmental, Social, and Governance dimensions, and presented through the ESGJoy web application. The platform provides interactive dashboards, industry benchmarking, metric-level analysis, role-specific views, and recommendations for users such as investors, companies, and regulators.

Key Features: Automated ESG extraction · Quantitative and qualitative metric processing · ESG scoring · Industry benchmarking · Interactive visualization · Role-based analysis · Sustainability recommendations

Tech: Python · pdfplumber · BERT · LLM · MySQL · Flask · Dash · Plotly · HTML

4. Multi-Agent Equity Analysis with Large Language Models

View GitHub Repository →

Developed a multi-agent equity analysis system in which four specialized analyst agents—fundamental, technical, sentiment, and adversarial— coordinate through a shared state rather than direct agent-to-agent calls. This design keeps individual agents modular, independently testable, and replaceable.

The system uses a two-tier prompt architecture that separates global rules for output format, tool use, and fallback behaviour from role-specific instructions governing each analyst's methodology and risk boundaries. An adversarial review stage then challenges the analyst reports for over-optimistic assumptions, under-weighted macro and governance risks, cross-report contradictions, fragile assumptions, and horizon-dependent forecasts.

Key Ideas: Shared-state coordination · Modular agent design · Structured prompting · Adversarial review · Cross-report consistency checking · Explainable synthesis

Tech: Python · MySQL · AkShare · Next.js · React · Streamlit

The project delivered a working system; no backtesting or forecast-validity evaluation was conducted.
